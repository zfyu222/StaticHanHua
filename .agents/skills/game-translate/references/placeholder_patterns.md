# 占位符/格式化字符串模式速查

> 按引擎/框架分类。禁翻表正则取自 `analyze_placeholders.py` 的输出，本表用于理解原理和手工补充。

## 通用格式化字符串（跨引擎）

| 类型 | 示例 | 保护正则 |
|------|------|----------|
| printf 风格 | `%s` `%d` `%.1f` `%1$s` `%%` | `%(?:\d+\$)?[0-9.+#-]*[sdfoxXeEfgGcr%]` |
| .NET String.Format | `{0}` `{1:0.00}` | `\{\d+(:[^{}\n]*)?\}` |
| Python str.format | `{name}` `{0}` | `\{[A-Za-z_][A-Za-z0-9_]*\}` |
| 美元变量（Twine/JS 等） | `${name}` `$player` | `\$\{[A-Za-z_][A-Za-z0-9_]*\}|\$[A-Za-z_][A-Za-z0-9_]*` |
| 字面转义 | `\n` `\r` `\t`（两字符） | `\\[nrt]` |

## Unity

| 类型 | 示例 | 保护正则 |
|------|------|----------|
| 富文本标签 | `<b>` `</color>` `<color=#FF0>` `<size=16>` | `</?[A-Za-z][^<>\n]{0,50}>` |
| 方括号变量（自定义） | `[Player:Name]` `[Victim:his/her]` | `\[[^\[\]\n]{1,60}\]`（按需收紧） |
| TextMeshPro Sprite | `<sprite=0>` `<sprite name="x">` | 含于富文本标签正则 |

注意：Unity 游戏自定义方括号变量格式千差万别，务必用 analyze 脚本从实际文本归纳。Expeditions Viking 的实际格式（供参考）：
`\[/?[A-Za-z][A-Za-z0-9]*(:[A-Za-z0-9/]+)?(="[^"]*")?\]` —— 覆盖 `[i]`、`[Player:man/woman]`、`[color="orange"]`、`[Stuck: his/her]`（含空格变体需放宽为 `\[[^\[\]\n]{1,60}\]`）。

## RPG Maker (MV/MZ/VX Ace)

AINiee 内置正则库已覆盖大部分，无需手工添加：
- 控制码 `\C[1]` `\N[1]` `\V[2]` `\FS<12>` `\fr` `\fb`
- 花括号 `{color=...}` `{image=...}` `{p}`
- 条件 `if(...)` `en(...)`

## Ren'Py

| 类型 | 示例 | 保护正则 |
|------|------|----------|
| 变量插值 | `[player_name]` `[score]` | `\[[^\[\]\n]{1,60}\]` |
| 文本标签 | `{i}` `{/i}` `{color=#f00}` `{size=+10}` | `\{/?[A-Za-z][^{}\n]{0,40}\}` |
| 特殊 | `[[`（转义字面 [） | 注意 `[[x]` 是字面 `[x]` 而非标签 |

## 其他常见

| 类型 | 示例 | 保护正则 |
|------|------|----------|
| HTML 实体 | `&amp;` `&lt;` `&#39;` | `&(?:amp|lt|gt|quot|apos|nbsp|#\d+);` |
| BBCode | `[b]` `[url=...]` `[/quote]` | `\[[^\[\]\n]{1,60}\]` |
| 全角标记（日式游戏） | `【名前】` | `【[^【】\n]{1,60}】` |

## 判别原则：什么该保护，什么不该

自定义流程的术语匹配使用与文本保护相同的实际规则（含家族覆盖、显式禁翻项及全文判定的 named-curly 开关）。保护区域内部不拆词参与术语匹配；完整标记本身作为明确的术语/禁翻项仍可命中。例：`[Player:man/woman]` 内部的 Player/man/woman 不命中普通词术语；`[i]Magic Sword[/i]` 中的正文 Magic Sword 正常命中。过滤发生在最长术语重叠裁决前，避免误匹配遮住真正的正文术语。

开启 whole_word 后，英文缩写撇号（`'`、`’`）也参与边界判断：Don 不再命中 don't/don’t，所有格 Don's/Don’s 与引号内的 Don 仍可命中。显式正则不改写；关闭 whole_word 仍允许子串。不得以此自动豁免 Rest/rest 一类同形普通词义，仍由模型结合原句解释并保存语境例外。

**应保护**（引擎运行时解析，翻译即损坏）：
- 含变量语义的标记：`[Player:Name]` `{0}` `%s` `${hp}`
- 渲染控制标签：`[i]` `<b>` `[color="red"]`
- 字面转义：`\n`（两字符）

**不应保护**（给玩家看的文本，需要翻译）：
- 花括号选项文本：`{Attack.}` `{Leave.}`（Expeditions Viking 风格）
- 普通括号注释、方括号内的完整句子

**判别方法**：机器型标记通常无空格、无句读、长度短、由字母数字和 `:_=/.#%` 组成。analyze 脚本的 curly 家族只匹配 `\{\d+\}` 和 `\{name\}`/`\{key=value\}` 这类机器型，句型 `{}` 不会误伤。
