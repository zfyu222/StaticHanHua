# 全自动审校的词义正反例（2026-10-24）

根据用户最新要求，优化现有独立审校提示，不把人工选句作为全自动流水线的前置步骤，也没有增加原文解读预处理阶段。此前的`import-review-readings`保留为辅助诊断入口，不能将它描述为已解决自动发现疑点。

## 默认行为

新生成的review/final_review任务在API和SubAgent两条路线共用以下要求，不需要用户开启或逐句标记：

- 先从原文确定动作参与者、修饰对象和语境词义，再对照现译；不要先替旧译找理由。
- 正反例区分头皮短发茬、下巴胡茬及原文明说头皮长胡须。前者误译为胡茬是accuracy错误，不能只当文风；后两种正确情形应保留。
- 对其他对象、动作和多义词同样核对。异常搭配回查原文，不用奇幻背景为原文不支持的误译开脱，也不按现实常识抹除明确设定。
- 正确且自然的译文保持，继续填写现有六维证据及完整修改译文，不新增输出字段、全文释义、额外模型阶段或关键词替换规则。

规则属于现有全部记录审校，不依赖人工先筛疑点。提示更明确仍不能保证模型不漏判；不能把“程序接收”和六维齐全当作语义必然正确。已接收结果及在途输入不重写，当前游戏不自动重审。

## 有界真实API对照

同一当前API、思考与并发配置，各用新建隔离项目测试旧提示和新提示。每组上限2次，合计上限4次；实际各1次、合计2次，均完成正式生成、请求、解析、落盘和整轮审校，无重试。

| 案例 | 旧提示 | 新提示 |
|---|---|---|
| 两条真实对白“胡茬的头皮” | 均改为短发茬 | 均改为短发茬 |
| close-cropped hair误作剪落的头发 | 修正 | 修正 |
| knitted her brows误作编织眉毛（未写入提示） | 改为皱眉 | 改为皱眉 |
| deeply lined face误作脸上画线（未写入提示） | 改为皱纹 | 改为皱纹 |
| 正确的头皮短发茬、下巴胡茬、原文明说的变种人头皮胡须 | 三条均保留 | 三条均保留 |
| 原文明说医生在脸上画线、女巫织眉毛装到玩偶上（未写入提示） | 两条均保留 | 两条均保留 |

两组都是**5条错误修正、5条正确译文保留**。新增样本的类别、期望译文及判断标签未作为元数据或诊断发给模型；原文和待审旧译按正常任务传入。病例由开发者选取，是回归测试，不是对全游戏随机抽样。头皮案例已在提示中举例，不能拿这些重复例子当泛化证据。

**没有测得新提示比旧提示更高的准确率。** 此次采用它是为了落实用户要求、把正确审校原则说明清楚，且本组未见回退；不能承诺靠提示词解决全部同类问题。此前旧接口的漏判记录仍保留，不改写成此次改动已证明有效。
